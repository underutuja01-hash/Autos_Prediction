# 🚘 AutoPrice AI – Car Price Prediction Using Machine Learning

## 📌 Project Overview

**AutoPrice AI** is a machine learning-based web application that predicts the estimated price of a car based on its dimensions, engine specifications, weight, and mileage information.

The application is developed using Python and Streamlit. It provides an interactive user interface where users can enter car specifications, generate a price prediction, view a sample automobile dataset, and download the prediction report.

## 🎯 Objectives

- Predict the estimated price of a car using Machine Learning.
- Understand how vehicle specifications influence car prices.
- Provide a simple and user-friendly prediction interface.
- Display car specifications in a structured table.
- Allow users to download prediction results as a CSV file.

## ✨ Features

- **Interactive UI:** Modern interface with a gradient background and styled cards.
- **Car Information Input:** Enter vehicle dimensions, engine details, and mileage.
- **Price Prediction:** Generate an estimated car price using a trained ML model.
- **Specification Summary:** Review the selected car details before prediction.
- **Dataset Preview:** View the first 10 records of the automobile dataset.
- **Download Report:** Export prediction results as a CSV file.
- **Error Handling:** Display error messages when required files are missing or prediction fails.

## ⚙️ Installation and Setup

### Step 1: Install Python

Install Python on your computer if it is not already installed.

### Step 2: Download the Project

Download or clone the project repository and open the project folder.

### Step 3: Install Required Libraries

Open Command Prompt or a terminal in the project folder and run:

```bash
pip install streamlit pandas scikit-learn
```

### Step 4: Prepare the Files

Keep the following files in the same folder:

- `app.py`
- `autos_dataset.csv`
- `car_price_model.pkl`

Rename the uploaded dataset file `autos_dataset(1).csv` to `autos_dataset.csv` before running the application.

### Step 5: Run the Application

Execute the following command:

```bash
streamlit run app.py
```

The application will open in your web browser.

## 🚀 How to Use

1. Launch the AutoPrice AI application.
2. Enter the car specifications in the sidebar.
3. Review the selected specifications in the summary table.
4. Click **Predict Car Price**.
5. View the estimated car price.
6. Download the prediction report if required.
7. Expand **View Sample Dataset** to inspect the automobile data.

## 📈 Expected Output

The application displays:

- An estimated car price in USD.
- A summary of the selected vehicle specifications.
- A downloadable CSV report containing the input features and predicted price.
- A preview of the automobile dataset.

The predicted price is an estimate generated by the trained model and may differ from the actual market price.
